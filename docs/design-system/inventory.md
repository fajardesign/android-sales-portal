## Temuan & hal ambigu
0. **⛔ Chip & Filter (2026-10-06)**: semua binding `Component/Chip/*` adalah variabel **remote dari library lain** (bukan koleksi lokal file ini). Contoh: border → `Border/Color/Stronger` (tidak ada di DS ini), padding vertikal memakai `Selection/Radius Medium`. Ditunda sampai desainer mengikat ulang ke variabel lokal (aturan #1 dan #8).
1. **Bottom Sheet `Inverse` hanya punya opsi `False`.** Deskripsi komponen dan aturan CLAUDE.md #7 mewajibkan `Inverse=True` untuk ilustrasi gelap, tetapi varian `True` tidak ada di Figma. Perlu konfirmasi desainer sebelum dibangun.
2. **Set tidak lengkap** (jumlah varian < kombinasi): Chip 11/12, Card 7/8, App Bar 8/12, Element / Icon 24/32, Bottom Sheet 4/16. Kombinasi yang hilang tidak akan dibuat tanpa konfirmasi.
3. **Nama ambigu / typo**: `Element / Stepper / Step` State=`State4`; `Elemet / User ID`; `Disabled - Fillled`; `TItle` (Modal / Default); `Pernission Device Data`; `Not Eligable Age`.
4. **Duplikat**: chevron / down double (`1125:363`, `288:735`), lock (`1120:363`, `1120:390`), Add 24 (`1644:6206`) vs Add 28 (`3084:6747`), Search vs Search 2, dua set bernama `Element / Detail / Approval` (`1421:1863`, `1756:6260`).
5. **Dua keluarga modal/button**: "Native" (Button Native, Modal / Native) vs custom (Button Group, Modal / Default). Perlu diputuskan apakah Native = dialog sistem Android (`AlertDialog`) dan tidak dibangun ulang.
6. **Alert `683:300`** adalah `COMPONENT_SET` (12 varian). `get_metadata` menampilkannya sebagai frame, tetapi traversal Plugin API mengonfirmasi set.
7. `get_metadata` tanpa node hanya melihat halaman *Logo*; daftar halaman lengkap di atas berasal dari traversal Plugin API read-only.
8. **Pemakaian di layar produk (2026-10-06)**: pindaian read-only halaman *Sales Portal* (Partner Info, Data Bisnis, Informasi PIC, Data Rekening, Document Upload, Login, Team Leader Dashboard). Dipakai: Sheet / Option 115×, Chip 63×, Card 53×, Upload Files & Element / Upload 45×, Logo 24×, Progress Photos 16×, Bottom Sheet 14×, Sheet / Illustration 7×, Sheet / Selection 2×. Tidak dipakai: keluarga Account/History, Stepper, Biometric, Face ID, Permission, Fern, Snowflake, User ID, Sheet / Text, Account Rejected.
9. **Tunaiku di Login**: bottom sheet Login memakai ilustrasi `Tunaiku` (4 varian) dan logo `lg-tunaiku` (24×). `lg-tunaiku` tidak ada di DS Lib Android. Perlu konfirmasi desainer.
10. **Card `Type=Default, Style=Shadow` tanpa shadow**: hanya `Type=Custom, Style=Shadow` yang memakai `Shadow/Floating` (detail di components.md).
